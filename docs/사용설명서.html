앱 개요

HiClear Badminton은 배드민턴 클럽의 코트 배정과 로테이션을 실시간으로 관리하는 웹 앱입니다. 약 30명 규모의 클럽에서 여러 코트를 효율적으로 운영하기 위해 설계되었습니다.

항목 내용
대상 기기태블릿 (1차), 데스크톱 (2차)
권장 클럽 규모약 30명
기본 코트 수6개 (추가/삭제 가능)
팀 구성A팀 2명 vs B팀 2명 (복식)
선호 편성남+여 vs 남+여 (남+남도 허용)
데이터 동기화Firestore 실시간 (여러 기기 동시 사용 가능)

화면 구성 & 네비게이션

앱 상단에 항상 고정된 네비게이션 바가 표시됩니다. 세 개의 주요 탭으로 이동합니다.

그림 2 — 네비게이션 바 (현재 활성 탭은 파란색 하이라이트)
탭경로주요 기능
선수 관리 /players 선수 등록, 삭제, 누적 게임 수 확인
대기열 /queue 대기 선수 순서 관리, 드래그 재정렬
코트 /courts 코트 배정, 게임 진행, 로테이션
팁
네비게이션 바 우측의 ↩ ↪ 버튼으로 언제든지 되돌리기/다시실행이 가능합니다.
3

선수 관리 /players

클럽 선수를 등록하고 관리하는 화면입니다. 여기서 등록된 선수만 대기열에 추가할 수 있습니다.

그림 3 — 선수 관리 화면

선수 등록 방법

  • 1이름 입력란에 선수 이름을 입력합니다.
  • 2남 또는 여 버튼을 눌러 성별을 선택합니다.
  • 3등록 버튼을 클릭합니다. 중복 이름은 등록되지 않습니다.

선수 삭제

선수 행 오른쪽의 × 버튼을 클릭하면 선수가 삭제됩니다.

주의
선수를 삭제하면 해당 선수의 대기열 및 코트 배정 정보도 함께 제거됩니다. 실수로 삭제했을 경우 ↩ 되돌리기 버튼으로 복구하세요.
4

대기열 관리 /queue

코트에 배정될 선수들의 대기 순서를 관리합니다. 대기열 상단의 선수가 우선적으로 코트에 배정됩니다.

그림 4 — 대기열 화면 (남/여 2컬럼 구분)

선수 대기열 추가

  • 1상단 검색창에 선수 이름을 입력합니다.
  • 2자동 완성 목록에서 선수를 선택하거나 직접 검색합니다.
  • 3대기열 추가 버튼을 클릭합니다. 이미 대기 중인 선수는 중복 추가되지 않습니다.

순서 변경 (드래그 & 드롭)

각 선수 행의 왼쪽 점 6개(⠿) 핸들을 잡고 드래그하면 순서를 바꿀 수 있습니다. 순서 변경은 남자/여자 컬럼 내에서만 가능합니다.

전체 대기열로 버튼

상단 전체 대기열로 버튼을 클릭하면 현재 모든 코트의 선수가 대기열로 이동합니다. 경기 종료 후 전체 리셋 시 사용합니다.

팁
대기열 순번(1, 2, 3...)은 실시간으로 반영됩니다. 코트에 자동 배정될 때는 남/여 관계없이 대기열 전체 순서대로 4명이 선발됩니다.
5

코트 관리 /courts

핵심 화면입니다. 코트별로 선수를 배정하고 게임을 진행합니다.

그림 5 — 코트 카드 (왼쪽: 배정 진행 중 / 오른쪽: 일반 상태)

코트 추가

  • 1화면 상단의 코트 번호 입력란에 번호를 입력합니다.
  • 2코트 추가 버튼을 클릭하면 대기열 상위 4명이 자동 배정됩니다.

선수 직접 배정

  • 1코트 카드의 A팀 또는 B팀 + 버튼을 클릭합니다.
  • 2화면 오른쪽에 대기열 패널이 열립니다. 배정 중인 코트 카드는 노란색 테두리로 강조됩니다.
  • 3패널에서 원하는 선수를 클릭하면 해당 팀에 배정됩니다.

코트 순서 변경

코트 카드 헤더 왼쪽의 점 6개(⠿) 핸들을 드래그하면 코트 순서를 변경할 수 있습니다.

코트 삭제

코트 헤더 오른쪽의 × 버튼을 클릭합니다. 해당 코트의 선수 전원이 자동으로 대기열로 이동합니다.

"대기열로" 버튼

각 코트 카드의 대기열로 버튼을 클릭하면 해당 코트의 선수 전원을 대기열로 보낼 수 있습니다.

6

게임 진행 규칙

코트에 A팀 2명 + B팀 2명이 모두 배정되면 게임이 시작됩니다. 게임 종료 후 매니저가 나오는 팀(패자)을 선택합니다.

게임 규칙 — 순서
  1. 게임이 끝나면 매니저가 나오는 팀(패자)을 선택합니다.
  2. 패자 팀 → 대기열 맨 뒤로 이동
  3. 승자 팀 → 코트에 잔류 (연승 카운터 +1)
  4. 대기열 상위 2명 → 패자 자리에 배정
  5. 2연속 승리 시: 승자 팀도 대기열로 이동 (코트 전체 교체)
그림 6 — 2연승 규칙 흐름도

연승 카운터 표시

코트 카드의 팀 이름 옆에 현재 연승 횟수가 숫자 배지로 표시됩니다.

  • 1 — 1연승 (다음 게임 이기면 교체)
  • 2 — 2연승 발동 후 교체 예정 (실제로는 즉시 교체됨)
중요
나오는팀 = 패자입니다. "A팀 나오는팀" 버튼은 A팀이 졌음을 의미합니다. 버튼 이름을 신중히 확인하고 클릭하세요. 실수 시 ↩ 되돌리기로 복구 가능합니다.
7

파트너 경고 기능

최근 같은 팀이었던 선수 조합을 자동으로 기억하여, 반복 편성을 방지합니다.

그림 7 — 선수 배정 패널의 파트너 경고 아이콘

작동 방식

  • 게임이 완료될 때마다 각 팀의 파트너 조합이 자동 저장됩니다.
  • 다음 배정 시, 같은 팀이었던 선수 이름 옆에 ↩ 아이콘이 표시됩니다.
  • 아이콘 위에 커서를 올리면 누구와 파트너였는지 확인 가능합니다.
  • 매니저가 직접 판단하여 다른 조합으로 배정할 수 있습니다.
팁
파트너 경고는 권고 사항입니다. 경고가 표시된 선수도 자유롭게 선택할 수 있습니다.
8

되돌리기 & 다시실행

실수로 잘못된 조작을 했을 때 빠르게 복구할 수 있는 기능입니다.

버튼기능최대 단계
↩ 되돌리기 마지막 작업을 취소합니다 10단계
↪ 다시실행 취소한 작업을 다시 적용합니다 10단계

되돌리기 가능한 작업

  • 게임 결과 처리 (나오는팀 선택)
  • 선수 코트 배정 / 제거
  • 대기열 순서 변경
  • 코트 추가 / 삭제
  • 선수 대기열 추가 / 제거
위치
되돌리기 / 다시실행 버튼은 네비게이션 바 우측에 항상 표시됩니다. 어느 화면에서든 사용 가능합니다.
9

파트너 초기화

세션(운동 모임)이 끝난 후 파트너 기록을 리셋하여 다음 모임을 새로 시작할 수 있습니다.

사용 방법

  • 1네비게이션 바 우측의 파트너 초기화 버튼을 클릭합니다.
  • 2확인 팝업이 나타납니다. 확인을 누릅니다.
  • 3화면 하단에 "파트너 기록이 초기화되었습니다" 토스트 알림이 표시됩니다.
주의
파트너 초기화는 파트너 기록만 삭제합니다. 선수 정보, 대기열, 코트 배정은 그대로 유지됩니다.
10

운영 팁

모임 시작 전

  • 선수 관리 화면에서 오늘 참석 선수를 대기열에 추가합니다.
  • 대기열에서 드래그로 선호 순서를 조정합니다.
  • 코트 추가 버튼으로 사용 코트를 설정합니다 (자동 4인 배정).

모임 중

  • 게임이 끝나면 즉시 나오는팀 버튼을 눌러 로테이션합니다.
  • 파트너 경고(↩) 아이콘을 참고하여 다양한 조합을 만듭니다.
  • 실수 시 즉시 ↩ 되돌리기 버튼을 사용합니다.

모임 종료 후

  • 파트너 초기화 버튼으로 파트너 기록을 리셋합니다.
  • 전체 대기열로 버튼으로 코트를 비웁니다.

여러 기기 동시 사용

앱은 Firebase Firestore를 사용하므로 여러 태블릿/PC에서 동시 접속 시 실시간으로 동기화됩니다. 별도 설정 없이 사용 가능합니다.

빠른 참조 — 버튼 요약
  1. A팀 나오는팀 — A팀이 패배, B팀 잔류
  2. B팀 나오는팀 — B팀이 패배, A팀 잔류
  3. 대기열로 — 해당 코트 선수 전원 → 대기열
  4. 전체 대기열로 — 모든 코트 선수 → 대기열
  5. ↩ 되돌리기 — 마지막 작업 취소 (최대 10단계)
  6. ↪ 다시실행 — 취소 작업 재적용
  7. 파트너 초기화 — 파트너 기록 전체 리셋
